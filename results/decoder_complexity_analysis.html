Decoder Complexity Analysis¶

This notebook investigates which properties of a surface-code decoding problem are associated with classical processing cost.

The analysis varies:

  • rotated surface-code distance;
  • circuit-level physical error probability;
  • number of syndrome-extraction rounds;
  • detector-graph size;
  • number and density of detection events;
  • decoder batch size.

The principal questions are:

  1. How does PyMatching runtime scale with code distance?
  2. Does higher physical noise increase decoding cost?
  3. Is detection-event count associated with individual decoding latency?
  4. Do logical decoding failures correspond to unusually dense detector samples?
  5. How strongly does batching reduce the effective time per shot?

The measured timings include Python, operating-system and hardware effects. They characterise the current software environment rather than the hardware-independent complexity of minimum-weight perfect matching.

def prepare_surface_code_workload(
    distance,
    physical_error_probability,
    number_of_shots,
    seed=SEED,
):
    """
    Generate a rotated surface-code memory circuit,
    decoder and detector samples.

    Syndrome rounds are set equal to code distance.
    """

    if distance < 3 or distance % 2 == 0:
        raise ValueError(
            "distance must be an odd integer "
            "greater than or equal to 3."
        )

    if not (
        0.0
        <= physical_error_probability
        <= 1.0
    ):
        raise ValueError(
            "physical_error_probability must be "
            "between zero and one."
        )

    if number_of_shots <= 0:
        raise ValueError(
            "number_of_shots must be positive."
        )

    rounds = distance

    circuit = stim.Circuit.generated(
        "surface_code:rotated_memory_x",
        distance=distance,
        rounds=rounds,
        after_clifford_depolarization=(
            physical_error_probability
        ),
        before_round_data_depolarization=(
            physical_error_probability
        ),
        before_measure_flip_probability=(
            physical_error_probability
        ),
        after_reset_flip_probability=(
            physical_error_probability
        ),
    )

    detector_error_model = (
        circuit.detector_error_model(
            decompose_errors=True
        )
    )

    decoder = (
        pymatching.Matching
        .from_detector_error_model(
            detector_error_model
        )
    )

    sampler = (
        circuit.compile_detector_sampler(
            seed=seed
        )
    )

    detection_events, actual_observables = (
        sampler.sample(
            shots=number_of_shots,
            separate_observables=True,
        )
    )

    return {
        "distance": distance,
        "rounds": rounds,
        "physical_error_probability": (
            physical_error_probability
        ),
        "circuit": circuit,
        "detector_error_model": (
            detector_error_model
        ),
        "decoder": decoder,
        "detection_events": (
            detection_events
        ),
        "actual_observables": (
            actual_observables
        ),
    }

def benchmark_surface_code_workload(
    distance,
    physical_error_probability,
    number_of_shots=20_000,
    individual_timing_shots=1_000,
    batch_timing_repeats=5,
    seed=SEED,
):
    """
    Measure batch throughput and sampled individual
    decoding latency for one surface-code workload.
    """

    workload = prepare_surface_code_workload(
        distance=distance,
        physical_error_probability=(
            physical_error_probability
        ),
        number_of_shots=number_of_shots,
        seed=seed,
    )

    circuit = workload["circuit"]
    decoder = workload["decoder"]
    detection_events = workload[
        "detection_events"
    ]
    actual_observables = workload[
        "actual_observables"
    ]

    detector_counts = detection_events.sum(
        axis=1
    )

    # Warm up the decoder.
    decoder.decode_batch(
        detection_events[:10]
    )

    batch_times = []

    for _ in range(
        batch_timing_repeats
    ):
        start_time = perf_counter()

        predicted_observables = (
            decoder.decode_batch(
                detection_events
            )
        )

        end_time = perf_counter()

        batch_times.append(
            end_time - start_time
        )

    batch_times = np.asarray(
        batch_times,
        dtype=float,
    )

    median_batch_time = float(
        np.median(
            batch_times
        )
    )

    decoding_failures = np.any(
        predicted_observables
        != actual_observables,
        axis=1,
    )

    logical_failure_count = int(
        decoding_failures.sum()
    )

    selected_shot_count = min(
        individual_timing_shots,
        number_of_shots,
    )

    # Sample throughout the dataset instead of using
    # only the first consecutive block.
    selected_indices = np.linspace(
        0,
        number_of_shots - 1,
        selected_shot_count,
        dtype=int,
    )

    individual_results = []

    # Warm up individual decode calls.
    for sample_index in selected_indices[:50]:
        decoder.decode(
            detection_events[
                sample_index
            ]
        )

    for sample_index in selected_indices:
        detector_sample = detection_events[
            sample_index
        ]

        start_time = perf_counter()

        decoder.decode(
            detector_sample
        )

        end_time = perf_counter()

        latency_microseconds = (
            1e6
            * (
                end_time - start_time
            )
        )

        individual_results.append(
            {
                "distance": distance,
                "rounds": distance,
                "physical_error_probability": (
                    physical_error_probability
                ),
                "shot_index": int(
                    sample_index
                ),
                "detection_events": int(
                    detector_counts[
                        sample_index
                    ]
                ),
                "detector_density": float(
                    detector_counts[
                        sample_index
                    ]
                    / circuit.num_detectors
                ),
                "latency_microseconds": (
                    latency_microseconds
                ),
                "logical_failure": bool(
                    decoding_failures[
                        sample_index
                    ]
                ),
            }
        )

    individual_df = pd.DataFrame(
        individual_results
    )

    summary = {
        "distance": distance,
        "rounds": distance,
        "physical_error_probability": (
            physical_error_probability
        ),
        "shots": number_of_shots,
        "qubits": circuit.num_qubits,
        "measurements": (
            circuit.num_measurements
        ),
        "detectors": (
            circuit.num_detectors
        ),
        "matching_edges": (
            decoder.num_edges
        ),
        "logical_failures": (
            logical_failure_count
        ),
        "logical_failure_probability": (
            logical_failure_count
            / number_of_shots
        ),
        "mean_detection_events": float(
            detector_counts.mean()
        ),
        "median_detection_events": float(
            np.median(
                detector_counts
            )
        ),
        "p95_detection_events": float(
            np.percentile(
                detector_counts,
                95,
            )
        ),
        "mean_detector_density": float(
            detector_counts.mean()
            / circuit.num_detectors
        ),
        "median_batch_seconds": (
            median_batch_time
        ),
        "batch_microseconds_per_shot": (
            1e6
            * median_batch_time
            / number_of_shots
        ),
        "batch_shots_per_second": (
            number_of_shots
            / median_batch_time
        ),
        "individual_samples": (
            len(
                individual_df
            )
        ),
        "individual_mean_microseconds": float(
            individual_df[
                "latency_microseconds"
            ].mean()
        ),
        "individual_median_microseconds": float(
            individual_df[
                "latency_microseconds"
            ].median()
        ),
        "individual_p95_microseconds": float(
            individual_df[
                "latency_microseconds"
            ].quantile(
                0.95
            )
        ),
        "individual_p99_microseconds": float(
            individual_df[
                "latency_microseconds"
            ].quantile(
                0.99
            )
        ),
    }

    return summary, individual_df

Decoder-complexity results¶

Increasing the surface-code distance increased the number of physical qubits, detectors and matching-graph edges. The larger graph and longer syndrome history increased the amount of classical information presented to the decoder.

Higher physical error probabilities produced more detection events per shot. This generally increased decoder workload, although detection-event count did not fully explain the observed single-shot latency. The spatial and temporal arrangement of events affects the matching problem, and the timing measurements also included Python-call overhead and operating-system variability.

Correlation analysis quantified the association between event count and latency. Pearson correlation measured linear association, while Spearman correlation measured whether latency tended to increase monotonically with event count.

The comparison between successful and failed decoding shots did not treat logical failure as equivalent to high computational difficulty. A decoder can return an incorrect logical prediction quickly if an alternative low-weight correction is more probable under its model. Logical failure is therefore a statistical inference failure rather than necessarily a performance failure.

Batch-size scaling showed substantial amortisation of call and setup overhead. Large batches achieved a much lower effective time per shot than individual decode calls. This is valuable for offline simulation throughput but cannot be assumed for real-time operation, where waiting for a large batch introduces additional latency.

The exploratory regression model assessed whether code distance, event count and physical error probability explained the measured latency. It should not be interpreted as a theoretical complexity result. Short-call performance can be dominated by language bindings, memory allocation, CPU scheduling and measurement resolution.

A hardware decoder should be evaluated using both algorithmic workload and system-level constraints. Relevant metrics include detector-graph scale, event density, worst-case or tail latency, sustained throughput, memory traffic, data-transfer overhead and the ability to process multiple logical qubits concurrently.
