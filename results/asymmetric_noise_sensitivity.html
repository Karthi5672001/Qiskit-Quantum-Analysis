Asymmetric-Noise Sensitivity Analysis¶

Previous simulations assigned the same physical error probability to Clifford gates, data qubits, measurements and resets. Real quantum hardware generally has different error rates for different operations.

This notebook studies how the logical failure probability responds independently to:

  • Clifford-gate depolarisation;
  • data-qubit depolarisation between syndrome rounds;
  • measurement-bit flips;
  • reset-bit flips.

The objectives are to:

  1. establish a common baseline noise model;
  2. vary one error source while holding the others fixed;
  3. measure the resulting logical failure probability;
  4. compare sensitivity across error mechanisms;
  5. identify which error source most strongly limits logical reliability;
  6. assess whether code distance changes the sensitivity ordering.

The results are specific to the generated rotated surface-code circuit, the selected decoder and the chosen baseline parameters. They should not be interpreted as universal hardware requirements.

def validate_noise_parameters(
    noise_parameters,
):
    """
    Validate a dictionary of circuit-level noise
    probabilities.
    """

    supplied_names = set(
        noise_parameters
    )

    if supplied_names != NOISE_PARAMETER_NAMES:
        missing_names = (
            NOISE_PARAMETER_NAMES
            - supplied_names
        )

        unexpected_names = (
            supplied_names
            - NOISE_PARAMETER_NAMES
        )

        raise ValueError(
            "Invalid noise-parameter names. "
            f"Missing: {sorted(missing_names)}. "
            f"Unexpected: "
            f"{sorted(unexpected_names)}."
        )

    for parameter_name, probability in (
        noise_parameters.items()
    ):
        if not 0.0 <= probability <= 1.0:
            raise ValueError(
                f"{parameter_name} must be "
                "between zero and one."
            )

def create_asymmetric_surface_code_circuit(
    distance,
    rounds,
    noise_parameters,
    memory_basis="x",
):
    """
    Generate a rotated surface-code memory circuit
    using separate circuit-level noise probabilities.
    """

    validate_noise_parameters(
        noise_parameters
    )

    memory_basis = memory_basis.lower()

    if memory_basis not in {
        "x",
        "z",
    }:
        raise ValueError(
            "memory_basis must be 'x' or 'z'."
        )

    if distance < 3 or distance % 2 == 0:
        raise ValueError(
            "distance must be an odd integer "
            "greater than or equal to three."
        )

    if rounds <= 0:
        raise ValueError(
            "rounds must be positive."
        )

    code_task = (
        "surface_code:rotated_memory_"
        f"{memory_basis}"
    )

    return stim.Circuit.generated(
        code_task,
        distance=distance,
        rounds=rounds,
        after_clifford_depolarization=(
            noise_parameters[
                "clifford_depolarisation"
            ]
        ),
        before_round_data_depolarization=(
            noise_parameters[
                "data_depolarisation"
            ]
        ),
        before_measure_flip_probability=(
            noise_parameters[
                "measurement_flip"
            ]
        ),
        after_reset_flip_probability=(
            noise_parameters[
                "reset_flip"
            ]
        ),
    )

def simulate_noise_configuration(
    distance,
    noise_parameters,
    number_of_shots,
    memory_basis="x",
    seed=SEED,
):
    """
    Generate, sample and decode one asymmetric-noise
    surface-code configuration.
    """

    if number_of_shots <= 0:
        raise ValueError(
            "number_of_shots must be positive."
        )

    rounds = distance

    circuit = (
        create_asymmetric_surface_code_circuit(
            distance=distance,
            rounds=rounds,
            noise_parameters=(
                noise_parameters
            ),
            memory_basis=memory_basis,
        )
    )

    detector_error_model = (
        circuit.detector_error_model(
            decompose_errors=True
        )
    )

    decoder = (
        pymatching.Matching
        .from_detector_error_model(
            detector_error_model
        )
    )

    sampler = (
        circuit.compile_detector_sampler(
            seed=seed
        )
    )

    sampling_start = perf_counter()

    detection_events, actual_observables = (
        sampler.sample(
            shots=number_of_shots,
            separate_observables=True,
        )
    )

    sampling_end = perf_counter()

    decoder.decode_batch(
        detection_events[:10]
    )

    decoding_start = perf_counter()

    predicted_observables = (
        decoder.decode_batch(
            detection_events
        )
    )

    decoding_end = perf_counter()

    decoding_failures = np.any(
        predicted_observables
        != actual_observables,
        axis=1,
    )

    logical_failure_count = int(
        decoding_failures.sum()
    )

    logical_failure_probability = (
        logical_failure_count
        / number_of_shots
    )

    if logical_failure_count > 0:
        standard_error = np.sqrt(
            logical_failure_probability
            * (
                1.0
                - logical_failure_probability
            )
            / number_of_shots
        )

        confidence_lower = max(
            0.0,
            logical_failure_probability
            - 1.96 * standard_error,
        )

        confidence_upper = min(
            1.0,
            logical_failure_probability
            + 1.96 * standard_error,
        )
    else:
        standard_error = np.nan
        confidence_lower = 0.0
        confidence_upper = (
            3.0 / number_of_shots
        )

    detection_event_counts = (
        detection_events.sum(
            axis=1
        )
    )

    sampling_seconds = (
        sampling_end - sampling_start
    )

    decoding_seconds = (
        decoding_end - decoding_start
    )

    return {
        "memory_basis": (
            memory_basis.upper()
        ),
        "distance": distance,
        "rounds": rounds,
        "shots": number_of_shots,
        **noise_parameters,
        "qubits": circuit.num_qubits,
        "detectors": circuit.num_detectors,
        "matching_edges": (
            decoder.num_edges
        ),
        "logical_failures": (
            logical_failure_count
        ),
        "logical_failure_probability": (
            logical_failure_probability
        ),
        "standard_error": (
            standard_error
        ),
        "confidence_lower_95": (
            confidence_lower
        ),
        "confidence_upper_95": (
            confidence_upper
        ),
        "mean_detection_events": float(
            detection_event_counts.mean()
        ),
        "median_detection_events": float(
            np.median(
                detection_event_counts
            )
        ),
        "p95_detection_events": float(
            np.percentile(
                detection_event_counts,
                95,
            )
        ),
        "sampling_seconds": (
            sampling_seconds
        ),
        "decoding_seconds": (
            decoding_seconds
        ),
        "decoder_microseconds_per_shot": (
            1e6
            * decoding_seconds
            / number_of_shots
        ),
    }

def create_modified_noise_model(
    baseline_noise,
    varied_parameter,
    multiplier,
):
    """
    Copy the baseline model and multiply one selected
    noise probability.
    """

    validate_noise_parameters(
        baseline_noise
    )

    if varied_parameter not in (
        NOISE_PARAMETER_NAMES
    ):
        raise ValueError(
            f"Unknown noise parameter: "
            f"{varied_parameter}"
        )

    if multiplier < 0.0:
        raise ValueError(
            "multiplier cannot be negative."
        )

    modified_noise = dict(
        baseline_noise
    )

    varied_probability = (
        baseline_noise[
            varied_parameter
        ]
        * multiplier
    )

    if varied_probability > 1.0:
        raise ValueError(
            "Modified probability exceeds one."
        )

    modified_noise[
        varied_parameter
    ] = varied_probability

    return modified_noise

sensitivity_results = []

configuration_index = 0
total_configurations = (
    len(VARIED_PARAMETERS)
    * len(NOISE_MULTIPLIERS)
)

for varied_parameter in (
    VARIED_PARAMETERS
):
    for multiplier in (
        NOISE_MULTIPLIERS
    ):
        configuration_index += 1

        noise_model = (
            create_modified_noise_model(
                baseline_noise=(
                    BASELINE_NOISE
                ),
                varied_parameter=(
                    varied_parameter
                ),
                multiplier=(
                    multiplier
                ),
            )
        )

        varied_probability = (
            noise_model[
                varied_parameter
            ]
        )

        print(
            f"Running "
            f"{configuration_index}/"
            f"{total_configurations} | "
            f"parameter={varied_parameter} | "
            f"multiplier={multiplier:.2f} | "
            f"probability="
            f"{varied_probability:.4%}"
        )

        result = (
            simulate_noise_configuration(
                distance=(
                    SENSITIVITY_DISTANCE
                ),
                noise_parameters=(
                    noise_model
                ),
                number_of_shots=(
                    SENSITIVITY_SHOTS
                ),
                memory_basis="x",
                seed=(
                    SEED
                    + configuration_index
                ),
            )
        )

        result[
            "varied_parameter"
        ] = varied_parameter

        result[
            "multiplier"
        ] = multiplier

        result[
            "varied_probability"
        ] = varied_probability

        sensitivity_results.append(
            result
        )

        print(
            f"  logical="

            f"failures="
            f"{result['logical_failures']:,} | "
            f"mean events="

local_sensitivity_results = []

for parameter_name in (
    VARIED_PARAMETERS
):
    subset = sensitivity_df[
        sensitivity_df[
            "varied_parameter"
        ] == parameter_name
    ]

    lower_row = subset[
        np.isclose(
            subset["multiplier"],
            0.5,
        )
    ].iloc[0]

    upper_row = subset[
        np.isclose(
            subset["multiplier"],
            2.0,
        )
    ].iloc[0]

    lower_logical_rate = lower_row[
        "logical_failure_probability"
    ]

    upper_logical_rate = upper_row[
        "logical_failure_probability"
    ]

    lower_physical_rate = lower_row[
        "varied_probability"
    ]

    upper_physical_rate = upper_row[
        "varied_probability"
    ]

    if (
        lower_logical_rate > 0.0
        and upper_logical_rate > 0.0
        and lower_physical_rate > 0.0
        and upper_physical_rate > 0.0
    ):
        logarithmic_sensitivity = (
            np.log(
                upper_logical_rate
                / lower_logical_rate
            )
            / np.log(
                upper_physical_rate
                / lower_physical_rate
            )
        )
    else:
        logarithmic_sensitivity = np.nan

    local_sensitivity_results.append(
        {
            "parameter": (
                parameter_name
            ),
            "parameter_label": (
                PARAMETER_LABELS[
                    parameter_name
                ]
            ),
            "logical_rate_at_half_baseline": (
                lower_logical_rate
            ),
            "logical_rate_at_double_baseline": (
                upper_logical_rate
            ),
            "logarithmic_sensitivity": (
                logarithmic_sensitivity
            ),
        }
    )

Asymmetric-noise results¶

The one-factor-at-a-time experiment separated the effects of Clifford-gate depolarisation, data-qubit depolarisation, measurement flips and reset flips. Each parameter was varied while the remaining error rates were held at their baseline values.

The logical failure probability did not necessarily respond equally to the same proportional change in each error source. This difference arose because the surface-code circuit contains different numbers of each operation and because faults at different circuit locations propagate into different detector and logical-error patterns.

The mean detection-event count increased as physical noise was raised. However, a larger increase in detector activity did not automatically imply the largest increase in logical failure. Some faults are readily detectable and correctable, while other combinations can form logical error chains.

The logarithmic sensitivity analysis ranked the error mechanisms by the proportional response of the logical failure probability near the chosen baseline. This ranking is specific to the generated circuit, baseline error values, code distance, number of syndrome rounds and PyMatching decoder.

The distance comparison showed whether increasing code distance continued to suppress logical errors under the modified noise models. Doubling one error source could reduce the benefit provided by larger codes even if the remaining physical error rates were unchanged.

The experiment used one-factor-at-a-time variation, so it did not capture interactions between error sources. For example, measurement and reset errors may combine differently from either mechanism in isolation. A full factorial or variance-based sensitivity study would be required to quantify such interactions.

The model also remained stochastic and Pauli based. It did not include leakage, coherent calibration errors, crosstalk, temporally correlated noise or spatially correlated faults. These mechanisms can violate the independence assumptions used by both the circuit model and matching decoder.

The practical implication for quantum-classical co-design is that decoder and architecture requirements depend on the complete hardware error profile. Optimising only an aggregate physical error rate can conceal which operations generate the dominant detector traffic and logical risk.
