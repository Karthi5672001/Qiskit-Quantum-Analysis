def interpolate_zero_crossings(
    x_values,
    y_values,
):
    """
    Linearly interpolate zero crossings between
    adjacent sampled points.
    """

    x_values = np.asarray(
        x_values,
        dtype=float,
    )

    y_values = np.asarray(
        y_values,
        dtype=float,
    )

    estimated_crossings = []

    for index in range(
        len(x_values) - 1
    ):
        x_left = x_values[index]
        x_right = x_values[index + 1]

        y_left = y_values[index]
        y_right = y_values[index + 1]

        if np.isclose(
            y_left,
            0.0,
        ):
            estimated_crossings.append(
                x_left
            )

        elif y_left * y_right < 0.0:
            fraction = (
                -y_left
                / (
                    y_right - y_left
                )
            )

            crossing = (
                x_left
                + fraction
                * (
                    x_right - x_left
                )
            )

            estimated_crossings.append(
                crossing
            )

    return estimated_crossings

Preliminary threshold result¶

The logical-failure curves show a finite-distance crossing region around a circuit-level physical error probability of approximately 0.65% to 0.70%.

Below this region, increasing the rotated surface-code distance reduced the logical decoding-failure probability. At a physical error probability of 0.3%, increasing the distance from 3 to 9 reduced the measured logical failure rate from approximately 6.91 × 10^-3 to 7.30 × 10^-4, an improvement of approximately 9.5 times.

Above the crossing region, increasing code distance increased the logical failure rate. At a physical error probability of 1%, the distance-9 logical failure rate was approximately 0.161, compared with approximately 0.067 for distance 3.

The crossing was not identical for every pair of finite distances. The distance-3 curve crossed the larger-distance curves earlier than the distance-5, distance-7 and distance-9 curves crossed one another. This is consistent with finite-size effects and means that the present result should be treated as a preliminary crossing region rather than a precise asymptotic threshold.

A refined study should sample more densely between physical error probabilities of 0.55% and 0.80%, include distance 11, and use uncertainty-aware finite-size scaling.
